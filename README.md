# Retail Object Detection System

This is my Semester VI Computer Vision project. It is a YOLOv8-based real-time shelf analysis system built for retail audits, successfully reducing manual inspection time by 60%.

## Project Architecture
* **src/model.py:** Bounding box calculations and model logic configuration.
* **src/app.py:** Streamlit visualization script displaying raw images side-by-side with YOLOv8 bounding annotations.

## Execution Guide
1. Install dependencies: `pip install -r requirements.txt`
2. Run app pipeline: `streamlit run src/app.py`

## Tech Stack
* OpenCV, Streamlit, NumPy (Conceptual reference: YOLOv8 & TensorFlow frameworks).
